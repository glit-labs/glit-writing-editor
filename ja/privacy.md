## アプリはデータを収集しません
当方は自社サーバーを運用せず、いかなる個人情報も収集・保存・共有しません。Glit には解析・広告・追跡のソフトウェアは含まれていません。アプリの利用にアカウントや登録は不要です。

## ファイルはお使いのデバイスに保存されます
あなたが作成または編集したすべてのプロジェクトとファイルは、お使いのデバイスにローカル保存されます。

Android では、テーマやエディタの設定などアプリ自身の設定が、端末の Google アカウントへのバックアップに含まれることがあります。クラウドのサインイン用トークンと購入状態は、そのバックアップから除外されています。

## クラウドストレージ（任意）
Glit はクラウドストレージを必要とせず、完全にオフラインで動作します。ご利用になる場合、その仕組みはプラットフォームによって異なります:

**macOS と Windows の場合:** クラウド提供元自身のデスクトップアプリ（Dropbox、OneDrive など）をインストールすると、コンピューター上に同期フォルダが作成され、その中で作業を同期します。Glit は他のローカルフォルダと同じように、そのフォルダでファイルを開いて保存するだけです。Glit 自体がクラウドサービスに接続したり、あなたのアカウントにアクセスしたりすることはありません。

**iPhone と iPad の場合:** Glit は公式 API を通じて Dropbox または Microsoft OneDrive に直接接続し、あなたが選んだファイルを同期します。サインインはサービスの安全な OAuth フローで行われ、認証トークンはお使いのデバイスに安全に保存され、当方に送信されることはありません。新しく接続する Dropbox は、Dropbox 内の Glit アプリフォルダのみを参照できます。Google Drive は新たに接続できなくなりました。すでに接続済みのプロジェクトはそのまま同期され、Glit はそのプロジェクトのファイルにのみアクセスします。アカウントのパスワードには決してアクセスしません。

**Android の場合:** Glit は公式 API を通じて Dropbox または Microsoft OneDrive に直接接続し、あなたが選んだファイルを同期します。サインインはサービスの安全な OAuth フローで行われ、認証トークンはお使いのデバイスに暗号化して保存され、当方に送信されることはありません。Glit はあなたが選んだフォルダの中だけでファイルを読み書きし、アカウントのパスワードにはアクセスしません。Google Drive との同期は、現時点では Android 版では提供していません。

## サードパーティのサービス
（どのプラットフォームでも）クラウドサービスを利用する際、そのサービスは各社独自のプライバシーポリシーに従います:

- Google（Google サインイン、Google Drive — 既存の接続のみ）: <https://policies.google.com/privacy>
- Dropbox: <https://www.dropbox.com/privacy>
- Microsoft（OneDrive）: <https://privacy.microsoft.com/privacystatement>

Glit が Google API から受け取った情報の使用および他のアプリへの転送は、限定的な使用（Limited Use）の要件を含め、[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) に準拠します。

## 購入について
お支払いの方法はプラットフォームによって異なります:

- **macOS と Windows:** 一度の買い切り購入でアプリのすべての機能が使えるようになります。
- **iPhone・iPad と Android:** 作品プロジェクト 1 つで無料で始められ、任意の買い切りアプリ内購入（Glit Pro）でこの制限がなくなります。メモ、フォルダ、クラウド同期はいつでも無料です。

サブスクリプションはありません。決済はアプリを入手したストア（Mac App Store、Microsoft Store、App Store、Google Play）が処理し、当方がお支払い情報を受け取ることは一切ありません。アプリは購入が有効かどうかだけを端末内に保存し、ストアに確認します。この記録が当方や第三者に共有されることはありません。

## ウェブサイトの分析
この項目は本ウェブサイトのみに適用されます。Glit アプリ自体は引き続き何も収集しません。

当方は、glit.app の訪問者数、どのページ・どの言語が読まれているか、どのサイトから来訪されたかを把握するために Cloudflare Web Analytics を利用しています。一般的な分析ツールに代えて、意図的にプライバシーに配慮した方式を選んでいます。

- **Cookie を使用しません。** お客様の端末には何も保存されず、継続的な識別子も付与されません。本サイトに Cookie 同意バナーがないのはこのためです。
- **収集する情報:** 閲覧したページ、来訪元のサイト、国、端末・ブラウザ・OS の種類、ページの読み込み速度。
- **収集しない情報:** お名前、メールアドレス、アプリで書かれた内容、アクセスされた URL のクエリ文字列。
- **訪問数の数え方:** Cloudflare が IP アドレス・ブラウザ・リクエストヘッダーから一時的な値を生成し、ハッシュ化したうえで破棄します。IP アドレスが保存されることはありません。
- **拒否の方法:** コンテンツブロッカーやトラッキング防止機能を使えばビーコンは実行されません。ブロックしても本サイトの利用に支障はありません。

Cloudflare による当該データの取り扱い: <https://www.cloudflare.com/privacypolicy/>
