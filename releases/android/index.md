# Glit for Android

**In development.** Glit is being built for Android phones and tablets, with the same writing workspace as the Mac, Windows, iPhone, and iPad versions. It is not on Google Play yet — this page is where the status lives until it is.

Quick memos, the five themes with a dark mode, and per-project settings all come across as well.

## Continuing a project from another device

A Glit project is just a folder of text files with a small settings file beside them, and every platform reads the same one. Sync that folder with Dropbox or OneDrive and open it on Android: the same episodes, ranges, statuses, and world-building are there.

Google Drive is not part of it: new Google Drive connections have been discontinued across Glit, so syncing runs on Dropbox and OneDrive.

## Pricing

The same as iPhone and iPad: free to start with one work project, and a one-time **Glit Pro** purchase adds unlimited projects. Notes, folders, and cloud sync are always free, and there is no subscription. Each store handles purchases separately, so a Google Play purchase does not carry to the App Store or the Microsoft Store — but your manuscripts are plain files you can open anywhere.

## Where it stands

The app is built and running on real phones and tablets: the editor, the web novel workspace, cloud sync, backups, and the Pro purchase have all been tested end to end. What is left is Google Play's pre-launch work — the store listing, the data safety form, and a closed testing round — plus a final pass of polish. There is no announced release date yet.

When it launches, this page becomes the Android release-notes index, and the version will appear on the [Releases](/releases.html) page and in the [Changelog](/CHANGELOG.html) alongside every other platform.

## In the meantime
