# Glit for Android Release Notes — v1.0.4

**Release date:** 2026-08-25  
**First public release (phones · tablets)**

---

## Overview

Glit comes to Android — a focused writing app for web novelists, now on Google Play for phones and tablets. Write each novel in its own dedicated project, organized by episodes and chapters, in the same project format the Mac, Windows, iPhone, and iPad versions already read.

---

## Key Features

### Web Novel Structure

Give each novel its own space and keep long manuscripts organized as you write. Episodes are filed into ranged folders, each with its own status and character count, and the world-building tree stays beside the manuscript.

### Distraction-free Editor with Focus Writing

A distraction-free Markdown editor built for long-form writing, with a full-screen focus mode, a character goal, and a timer.

### Cloud Sync (free)

Sync your work with Dropbox or OneDrive to pick up where your desktop left off — no extra cost — or keep everything on the device.

### Memos, Search &amp; Backups

Quick memos, folders, full-text search across a project, and automatic backups with a recoverable trash.

### Free / Glit Pro

- **Free**: one work project.
- **Glit Pro** (one-time purchase): unlimited work projects, so every story has its own space.
- No subscription. No account required to start writing.

---

## Requirements

- Android 8.0 or later
- Phones and tablets
- Available in 8 interface languages
