# Glit for iOS Release Notes — v1.4.0

**Release date:** 2026-08-23  
**Update for iPhone · iPad**

---

## Overview

Version 1.4.0 tidies up how Glit connects to the cloud. New Dropbox connections stay inside a single folder, and the projects you already sync keep working exactly as before.

---

## What's New

### Dropbox App Folder

New Dropbox connections use only the Glit app folder inside Dropbox. Glit cannot see anything outside that folder.

### Your Existing Projects

Projects you already sync keep working exactly as before — no re-login, nothing to move. Opening a project that uses an earlier connection shows a short notice explaining your options.

### Google Drive Connections

Google Drive can no longer be connected. Projects already connected to it keep syncing.

---

## Requirements

- iOS / iPadOS 17.0 or later
