# Glit Release Notes — v1.5.0

**Release date:** 2026-10-25  
**Previous version:** v1.4.0

---

## New Features

### Bespoke Pomodoro

In Web Novel Mode, write in alternating focus and break sessions. Start it from the button in the editor's top bar or from the Focus Writing settings, and choose a break sound (Water or Birds) and a 1-minute warning chime. See the [Bespoke Pomodoro guide](/guides/bespoke-pomodoro.html) for a step-by-step walkthrough.

### Tables from the right-click menu

Add tables, and insert or delete rows and columns, from the right-click menu in the Markdown editor.

### Word count

Click the character count at the top of the editor to choose Characters, Characters (incl. spaces), or Words.

### Export Project

Right-click a project name in the sidebar to export the project folder as a .zip file.

## Improvements

- In Web Novel Mode, right-click an episode and choose "Rename", or double-click it, to edit the episode title.
- Click a file's extension label in the sidebar to switch between MD and TXT.
- Quitting the app or closing the last window now fully exits the app.
