# Glit リリースノート — v1.2.1

**リリース日:** 2026-07-02  
**以前のバージョン:** v1.1.1

---

## 新機能 / 改善

### テーマ刷新 — システム（System）とペーパー（Paper）を追加、クリーンを削除

テーマの構成を刷新しました。システム（System）とペーパー（Paper）テーマを追加し、クリーン（Clean）テーマは廃止しました。

- **システム（System）**: OS のライト／ダークモードに自動で追従するニュートラルなパレットです。システムがダークモードに切り替わると、本文とタイトルバーも即座に切り替わります。
- **ペーパー（Paper）**: 明るい紙のような背景に、落ち着いたネイビーのアクセントカラーを組み合わせたテーマです。
- これまでクリーンテーマをお使いだった場合は、自動的にペーパーテーマへ移行されます。
- 新規インストール時のデフォルトテーマは、従来どおりウォームス（Warmth）です。

### 意図しない改行の識別を改善（韓国語）

入力中に自動折り返しと実際の改行（Enter）を見分けにくかった問題を改善しました。

- **改行を表示** トグル: 実際の改行位置に薄い `↵` マーカーを表示します。本文の折り返し位置には影響せず、デフォルトはオフです。
- **改行方式** の選択（韓国語）: 音節単位（デフォルト）と単語単位のいずれかを選択できます。音節単位は、ウェブ小説リーダーと同じ方式で本文を表示します。

### プレビュー（デバイス）— 設定をオプションポップアップに移動

プレビュー（デバイス）ウィンドウのツールバーにあったデバイス選択と文字サイズ調整を「設定」ポップアップにまとめました。ウィンドウのタイトルは中央揃えになりました。

### 画像ビューアの UI 整理

画像ビューアのファイル名がウィンドウ中央に揃えられ、ズームコントロールが下部ステータスバーの右側へ移動しました。

## バグ修正

### プレビュー（デバイス）: 編集内容がリアルタイムに反映されない

エディタで文章を編集してもプレビュー（デバイス）ウィンドウにリアルタイムで反映されない問題を修正しました。
