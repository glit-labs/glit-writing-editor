# Glit 发布说明 — v1.3.0

**发布日期：** 2026-08-24  
**上一版本：** v1.2.3

---

## 新功能 / 改进

### Dropbox 云端文件夹同步

新增 Dropbox 云端文件夹同步。可上传和下载作品文件夹，在多台设备上继续写作。

### 与 Dropbox 比较

可将本地稿件与 Dropbox 的内容进行比较，查看具体差异。

### 版本记录

同步过程中被覆盖或清理的稿件会保存到版本记录，随时可以恢复。
