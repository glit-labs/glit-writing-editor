# Glit 发布说明 — v1.4.0

**发布日期：** 2026-10-02  
**上一版本：** v1.3.1

---

## 新功能

### OneDrive 同步

可将作品文件夹与 OneDrive 同步。在云端文件夹窗口中，可通过标签页选择 Dropbox 或 OneDrive。

### 通过右键菜单插入图片

可通过 Markdown 编辑器的右键菜单插入图片。

### 预览跟随输入位置

可设置预览跟随编辑器中的输入位置。

### 在侧边栏切换网络小说创作模式

可在侧边栏直接切换网络小说创作模式。

## 改进

- 从云端下载时，会提示未能处理的项目。
- 检测到范围文件夹重叠时会提示，并可在应用内整理。
- 预览中的英文单词不再从中间断开。
- 完善了多种语言的翻译。
