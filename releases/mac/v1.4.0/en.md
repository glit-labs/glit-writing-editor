# Glit Release Notes — v1.4.0

**Release date:** 2026-10-02  
**Previous version:** v1.3.1

---

## New Features

### OneDrive support

Sync a work folder with OneDrive. In the cloud folder window, choose Dropbox or OneDrive from the tabs.

### Insert images from the right-click menu

Insert images from the right-click menu in the Markdown editor.

### Preview follows your typing

The preview can follow the position you are typing in the editor (optional setting).

### Web Novel Mode from the sidebar

Turn Web Novel Mode on or off directly from the sidebar.

## Improvements

- Items that could not be processed when downloading from the cloud are now reported.
- Overlapping range folders are detected, and you can resolve them within the app.
- English words are no longer broken mid-word in the preview.
- Improved translations in several languages.
