# Glit Release Notes — v1.3.1

**Release date:** 2026-08-27  
**Previous version:** v1.3.0

---

## Improvements

- Dropbox uploads now finish in a single pass. Previously some items were left behind and had to be uploaded again.
- Cloud folders now open only after you select a work, so a stray click no longer opens the wrong one.
- When an upload finishes, the Dropbox-linked copy opens right away.
- Before uploading, you can see where the folder is copied and uploaded to, and whether anything is still unsaved.
- If any items could not be processed, they are listed so you can upload them again.
