# Glit Notas de la versión — v1.3.1

**Fecha de lanzamiento:** 2026-08-27  
**Versión anterior:** v1.3.0

---

## Mejoras

- Las subidas a Dropbox se completan de una sola vez. Antes quedaban elementos sin procesar y había que volver a subirlos.
- Las carpetas en la nube ahora se abren tras seleccionar la obra, así un clic accidental no abre la equivocada.
- Al terminar la subida se abre directamente la copia vinculada a Dropbox.
- Antes de subir puedes ver a dónde se copia y se sube la carpeta, y si queda algo sin guardar.
- Si algún elemento no se ha podido procesar, se muestra en una lista para volver a subirlo.
