# Glit Notes de version — v1.3.1

**Date de sortie :** 2026-08-27  
**Version précédente :** v1.2.3

## Nouveautés / Améliorations

### Synchronisation avec les dossiers Dropbox

Ajout de la synchronisation avec les dossiers Dropbox. Envoyez et téléchargez vos dossiers d'œuvre pour continuer à écrire sur plusieurs appareils. Sélectionnez une œuvre dans le dossier cloud avant de l'ouvrir ; une fois l'envoi terminé, la copie liée à Dropbox s'ouvre directement.

### Comparer avec Dropbox

Comparez vos manuscrits locaux avec Dropbox pour voir précisément ce qui diffère.

### Historique des versions

Tout ce qu'une synchronisation écrase ou supprime est conservé dans l'historique des versions et peut être restauré à tout moment.
