# Glit Release Notes — v1.3.1

**Release date:** 2026-08-27  
**Previous version:** v1.2.3

---

## New Features / Improvements

### Dropbox cloud folder sync

Added Dropbox cloud folder sync. Upload and download your work folders to keep writing across devices. Pick a work in a cloud folder before opening it, and when an upload finishes the Dropbox-linked copy opens right away.

### Compare with Dropbox

Compare your local manuscripts with Dropbox to see exactly what differs.

### Version history

Anything a sync overwrites or removes is kept in version history, so you can restore it at any time.
