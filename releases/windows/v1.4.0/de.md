# Glit Versionshinweise — v1.4.0

**Veröffentlicht:** 2026-10-03  
**Vorherige Version:** v1.3.1

---

## Neue Funktionen

### OneDrive-Anbindung

Werkordner lassen sich mit OneDrive synchronisieren. Im Cloud-Ordner-Fenster wählen Sie Dropbox oder OneDrive über Tabs aus.

### Bilder über das Kontextmenü einfügen

Bilder lassen sich über das Kontextmenü im Markdown-Editor einfügen.

### Vorschau folgt der Eingabe

Die Vorschau kann der Eingabeposition im Editor folgen (optional einstellbar).

### Fortsetzungsroman-Modus in der Seitenleiste

Den Fortsetzungsroman-Modus können Sie direkt in der Seitenleiste ein- und ausschalten.

## Verbesserungen

- Elemente, die beim Herunterladen aus der Cloud nicht verarbeitet werden konnten, werden gemeldet.
- Überlappende Bereichsordner werden erkannt und lassen sich direkt in der App bereinigen.
- Englische Wörter werden in der Vorschau nicht mehr mitten im Wort getrennt.
- Übersetzungen in mehreren Sprachen verbessert.
